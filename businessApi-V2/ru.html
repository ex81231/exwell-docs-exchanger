Документация Exwell API

Все запросы содержат query-параметр key — API-ключ из партнёрского кабинета. Формат ключа: 32 символа A–Z a–z 0–9. Без ключа или с неверным ключом API отвечает 401.

API URI https://exwell.io/v1/api — то же, что https://api.exwell.io/partner/v1/
Ответ json, кроме XML-фида курсов
Авторизация только key. Параметр refId с сайта API не читает
Комиссия начисляется, только если в кабинете задан Partner Fee Rate. Иначе обмен пройдёт, начисления не будет
Ошибки 401 — нет key (Key parameter is required!) или ключ не найден (User does not exist!). Остальные коды — у метода

Обмен

Порядок вызовов

  1. /currencies — какие монеты есть
  2. /pairs — какие пары открыты
  3. /rate — курс и лимиты на сумму
  4. /validate-address — адрес получения
  5. /exchange-create — заявка, депозитный адрес
  6. Пользователь отправляет депозит
  7. /exchange-status — поллинг до финального статуса

Курсы в формате XML

Фид курсов всех открытых пар. Не путать с JSON /rate (одна пара и сумма). Ответ application/xml: корень <rates>, элементы <item>.

v1 и v2 отдают одни и те же данные. Отличие — имена тегов минимума и максимума (лимиты по валюте from):

v1 v2
URL https://exwell.io/v1/api/rate.xml https://api.exwell.io/partner/v2/rate.xml
минимум <minamount> <frommin>
максимум <maxamount> <frommax>

Остальные теги одинаковые: from, to, in, out, amount, param. Префикс сайта /v1/api на v2 не мапится.

Порядок

  1. Подставить key в URL фида
  2. Периодически забирать XML

GET /rate.xml — Курсы XML v1

Публичный URI — тот же префикс /v1/api.

https://exwell.io/v1/api/rate.xml?key=Kq8WmP2nXrT5vLcYhB7jFdZuAs4gE9oN

Дополнительных параметров нет.

Ответ 200 application/xml

<rates>
  <item>
    <from>BTC</from>
    <to>USDTTRC20</to>
    <in>1</in>
    <out>68420.15</out>
    <minamount>0.001</minamount>
    <maxamount>5</maxamount>
    <amount>150000</amount>
    <param>floating</param>
  </item>
</rates>
Тег Тип Смысл
from string валюта отправки
to string валюта получения
in int входной коэффициент, всегда 1
out string курс: сколько to за in единиц from
minamount string минимум по from
maxamount string максимум по from
amount string резерв
param string всегда floating

GET /partner/v2/rate.xml — Курсы XML v2

Те же пары и значения, что у v1. Лимиты — теги frommin / frommax. Префикс сайта /v1/api сюда не мапится — вызывайте хост API.

https://api.exwell.io/partner/v2/rate.xml?key=Kq8WmP2nXrT5vLcYhB7jFdZuAs4gE9oN

Дополнительных параметров нет.

Ответ 200 application/xml

<rates>
  <item>
    <from>BTC</from>
    <to>USDTTRC20</to>
    <in>1</in>
    <out>68420.15</out>
    <frommin>0.001</frommin>
    <frommax>5</frommax>
    <amount>150000</amount>
    <param>floating</param>
  </item>
</rates>
Тег Тип Смысл
from string валюта отправки
to string валюта получения
in int входной коэффициент, всегда 1
out string курс: сколько to за in единиц from
frommin string минимум по from (в v1 — minamount)
frommax string максимум по from (в v1 — maxamount)
amount string резерв
param string всегда floating

Кошелёк

Адреса кабинета (main и test) и USDT-баланс внутри ресурса кошелька. Аренда TRX Energy списывается с этого баланса, не on-chain с адреса клиента. Тестовая сеть TRON — Nile (в ответе TESTNET).

Порядок, если нужна энергия

  1. GET /wallet — адреса MAINNET и TESTNET
  2. Депозит USDT TRC20 на адрес нужной сети
  3. GET /wallet/balance — хватает ли USDT
  4. Дальше — раздел TRX Energy

TRX Energy

Аренда энергии TRON. Списание с USDT-баланса кабинета. Query network=TESTNET — Nile; MAINNET или без network — основная сеть (оценка, аренда, список и статус заказа). Nile-заказ ищите с network=TESTNET.

Порядок вызовов

  1. /wallet/trx-energy/info — лимиты
  2. /wallet/trx-energy/energy-required — цена; address = получатель энергии
  3. POST /wallet/trx-energy — заказ, сразу PROCESS
  4. GET /wallet/trx-energy/{orderId} — поллинг PROCESS → SUCCESS / ERROR

GET /wallet/trx-energy/info — Лимиты аренды

Периоды и min/max energy. Баланса здесь нет — смотрите /balance.

https://exwell.io/v1/api/wallet/trx-energy/info?key=Kq8WmP2nXrT5vLcYhB7jFdZuAs4gE9oN

Дополнительных параметров нет.

Ответ 200

{
  "periods": ["H1", "D1", "D3", "D30"],
  "minEnergy": 10000,
  "maxEnergy": 1000000
}

Поле periods — справочно. В теле аренды period нет.

GET /wallet/trx-energy/energy-required — Оценка

Цена аренды. address — адрес получателя энергии (не обязан быть кошельком партнёра). Без energyAmount система считает потребность этого адреса сама. Без network — MAINNET.

https://exwell.io/v1/api/wallet/trx-energy/energy-required?key=Kq8WmP2nXrT5vLcYhB7jFdZuAs4gE9oN&address=TExWKszFWYTKZH8LYiovAPKzS3L9MLZ4kw&energyAmount=65000&network=MAINNET

Параметры

Параметр Тип Пример
address string TRON-адрес получателя
energyAmount optional int 65000
network optional string MAINNET или TESTNET

Ответ 200

{
  "recipientAddress": "TExWKszFWYTKZH8LYiovAPKzS3L9MLZ4kw",
  "energyRequired": 65000,
  "price": 0.86,
  "priceSymbol": "USDT"
}

price — к списанию, уже с наценкой.

Ошибки: 409 — битый адрес или объём вне лимитов.

POST /wallet/trx-energy — Аренда

Создаёт заказ. Ответ сразу со статусом PROCESS — дальше поллинг по id в той же сети (без network статус ищется в MAINNET).

https://exwell.io/v1/api/wallet/trx-energy?key=Kq8WmP2nXrT5vLcYhB7jFdZuAs4gE9oN&network=MAINNET

Body application/json

{
  "recipients": [
    {
      "address": "TExWKszFWYTKZH8LYiovAPKzS3L9MLZ4kw",
      "energy": 65000
    }
  ]
}

Параметры

Параметр Тип Пример
network optional string MAINNET или TESTNET
recipients body object[] [{"address":"TAddr...","energy":65000}]

Ответ 200

[
  {
    "id": 48,
    "recipientAddress": "TExWKszFWYTKZH8LYiovAPKzS3L9MLZ4kw",
    "rentEnergy": 65000.0,
    "sellingPrice": 0.86,
    "sellingPriceSymbol": "USDT",
    "status": "PROCESS",
    "createdAt": "2026-08-26T12:00:00"
  }
]

Ошибки: 409 — мало баланса; объём вне лимитов (info); битый адрес; больше 10 получателей.
